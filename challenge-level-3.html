LEVEL 3 - INTERAKTIF DENGAN FORM!

Tantangan HTML #3: Website Pendaftaran Event / Lomba

Mantap sudah sampai di Level 3! Kali ini kamu akan membuat Website Informasi & Formulir Pendaftaran Event (misalnya lomba coding, turnamen game, acara sekolah, atau festival komunitas).
Aturan Utama: Semua tag dari Level 1 & Level 2 tetap harus dipakai (h1-h3, p, img, a, <br>, table kompleks, dan nested list), ditambah elemen Formulir HTML baru: <form>, <input> (biasa, radio, checklist/checkbox), <textarea>, dan <button>!

Kerjakan di file event-level-3.html.

Syarat Wajib Tag Baru (Level 3)

Di bagian formulir pendaftaran, wajib ada semua komponen berikut ini:

No Komponen Form Contoh Penggunaan di Pendaftaran Event Tag & Atribut Petunjuk
1 Wadah Form Membungkus seluruh input dan tombol pendaftaran <form action="#" method="post">...</form>
2 Input Biasa Kolom isi Nama Lengkap, Email, Umur / Nomor HP <input type="text">, type="email", type="number" (pakai placeholder="..." & required)
3 Input Radio Memilih 1 pilihan saja, misalnya Kategori Peserta (SD / SMP / SMA) atau Jenis Lomba <input type="radio" name="kategori" value="..."> (name harus sama!)
4 Checklist (Checkbox) Memilih lebih dari satu, misalnya Sesi Workshop yang diikuti / Perlengkapan yang dibawa, plus centang persetujuan aturan <input type="checkbox" name="..." value="...">
5 Textarea Kolom isian panjang untuk Alamat Lengkap, Alasan Mengikuti Event, atau Catatan Khusus <textarea rows="4" cols="40" placeholder="..."></textarea>
6 Button Tombol untuk mengirim formulir ("Daftar Sekarang") dan tombol mengosongkan isi form ("Reset") <button type="submit"> dan <button type="reset">

Syarat Tag Lama yang Tetap Harus Ada

  • Heading bertingkat: <h1>, <h2>, dan <h3>.
  • Link navigasi internal: Menu di atas yang melompat ke #info, #jadwal, #peraturan, dan #daftar, plus link ke halaman Level 1 / Level 2 dan gambar yang bisa diklik.
  • Paragraf & <br>: Cerita/deskripsi event dan kontak panitia memakai <br>, serta <br> untuk merapikan baris di dalam formulir.
  • Gambar (<img>): Minimal 2 gambar berbeda ukuran (banner event dan ikon/gambar di tabel atau link).
  • Tabel Kompleks: Tabel Jadwal Acara & Hadiah minimal 4 kolom, ada colspan / rowspan, dan ada <img> / <br> di dalam <td>.
  • Nested List: Peraturan lomba dan daftar perlengkapan (list di dalam list).

Tips Penting Saat Membuat Form

  1. Untuk Input Radio, pastikan atribut name="..." sama di satu kelompok pilihan supaya user hanya bisa memilih satu opsi.
  2. Gunakan <label> agar teks di sebelah radio atau checkbox bisa ikut diklik!
  3. Tambahkan atribut required pada input wajib seperti Nama dan Email agar tidak bisa dikirim kalau masih kosong.
  4. Tetap fokus pada HTML murni tanpa CSS/JavaScript dulu.
