Tantangan HTML: Buat Website Data Diri!

Halo! Selamat datang di tantangan pertama membuat halaman web menggunakan HTML murni.
Tugasmu adalah membuat Website Data Diri (Biodata / Profil Pribadi) di file data-diri.html (atau buat file HTML baru sendiri).

Syarat Wajib (Harus Ada Semua!)

Pastikan halaman data dirimu memiliki 7 elemen HTML berikut ini:

No Elemen Wajib Contoh Penggunaan di Website Data Diri Tag HTML Petunjuk
1 Heading Judul utama nama lengkapmu dan subjudul bagian (misal: Tentang Saya, Hobi, Riwayat Pendidikan) <h1>, <h2>, <h3>
2 Paragraf Deskripsi singkat perkenalan diri, cita-cita, atau cerita singkat tentang dirimu <p>
3 Gambar Foto profil atau gambar favoritmu (bisa pakai file lokal seperti ayam.jpg atau foto lain) <img src="..." alt="...">
4 Link Tautan ke media sosial (Instagram, YouTube, GitHub) atau website favoritmu <a href="...">...</a>
5 Ganti Baris (<br>) Membuat baris baru di dalam alamat rumah, kontak, atau kutipan favorit tanpa membuat paragraf baru <br>
6 Tabel Tabel biodata ringkas (Nama, TTL, Alamat) atau tabel Riwayat Pendidikan / Jadwal Harian <table>, <tr>, <th>, <td>
7 List Daftar hobi, makanan favorit, atau daftar keahlian yang ingin dipelajari <ul> / <ol> dan <li>

Ide Susunan Website Data Diri

  1. Bagian Atas: Judul nama kamu (<h1>) dan foto profil (<img>).
  2. Tentang Saya: Subjudul (<h2>) + paragraf perkenalan diri (<p>) + alamat/motto yang memakai <br>.
  3. Biodata / Pendidikan: Tabel rapi berisi informasi diri atau daftar sekolah (<table>).
  4. Hobi & Kesukaan: Daftar hobi atau skill menggunakan list (<ul> atau <ol>).
  5. Kontak / Sosmed: Link ke Instagram, YouTube, atau website lain (<a>).

Tantangan Tambahan (Opsional)

  • Tambahkan atribut alt yang jelas pada semua gambar.
  • Buat link terbuka di tab baru menggunakan atribut target="_blank".
  • Gunakan tag <strong> atau <em> / <i> untuk menebalkan atau memiringkan kata penting.
  • Tambahkan garis pemisah antar bagian menggunakan <hr>.

Semangat ngoding! Buka file data-diri.html di editor untuk mulai mengerjakan.
